## 📌 Project Overview
- **개발 기간:** 2019.05 ~ 2019.07 (3개월)
- **개발 인원:** 3인 팀 프로젝트 (프로그래밍 1명, 아트 1명, 맵 기획 1명)
- **담당 역할:** 메인 프로그래머 (Unity 클라이언트 로직 및 물리 엔진 구현 전담)
- **장르:** 2D 플랫포머 어드벤처, 생존

## 🎮 Game Concept
깊은 동굴 속에 갇힌 플레이어가 **함정과 몬스터를 피해 로프를 활용하여 무사히 탈출**하는 스토리를 담고 있습니다. 
단순한 이동을 넘어 **HP, 산소, 횃불, 음식**이라는 4가지 핵심 생존 요소를 수시로 체크하며 탐험해야 하는 긴장감 있는 플레이가 특징입니다.

## 🛠 Tech Stack
### **Engine & Languages**
- Unity 2D
- C#

### **Key Technologies**
- **Tilemap:** 동굴 레벨 디자인 및 콜라이더 병합(Composite Collider 2D)
- **Joint 2D (Hinge/Distance):** 로프를 활용한 진자 운동 및 스윙 액션 물리 구현
- **Particle System:** 횃불 이펙트, 타격 효과 등 시각적 연출
- **2D Lighting:** 어두운 동굴 속 횃불 기반의 동적 시야 제한 및 광원 효과

### **Tools**
- **Photoshop CS6:** 픽셀 아트 이미지 규격화 및 피벗 정규화
- **GoldWave:** 인터넷 무료 사운드 소스를 게임의 분위기에 맞게 직접 편집하여 BGM/SFX로 적용

## 🔥 Collaboration & Problem Solving

단순히 코드의 버그를 고치는 것을 넘어, **팀 전체의 파이프라인을 개선하고 작업 효율을 높인 협업 경험**입니다.

### 🚩 아트 리소스 규격(PPU/Pivot) 불일치 문제
개발 초기, 아트 담당자가 그려주는 픽셀 이미지들의 캔버스 사이즈와 피벗(Pivot) 기준점이 통일되지 않은 채 전달되었습니다. 이로 인해 맵 기획자가 타일맵을 조립하거나 캐릭터 애니메이션을 연결할 때 그래픽이 묘하게 어긋나는 문제가 빈번하게 발생했습니다.

### 💡 포토샵 정규화 및 가이드라인 정립을 통한 해결
초기에는 마감 일정을 맞추기 위해 제가 직접 **포토샵(Photoshop CS6)을 켜서 이미지들을 일일이 정규화(Normalize)**하여 유니티에 임포트하는 수고를 감수했습니다. 
하지만 이는 장기적으로 비효율적이라 판단하여 근본적인 해결에 나섰습니다. 
1. 아트 담당자에게 유니티 에디터 상에서 **에셋 규격(Pixels Per Unit) 통일이 왜 필수적인지** 문제를 명확히 공유했습니다.
2. 포토샵에서 캔버스 사이즈를 규격화하고 피벗을 일정하게 맞추어 이미지를 추출하는 방법을 **직접 가이드해 주고 교육**했습니다.

이후 리소스가 일관된 규격으로 깔끔하게 전달되면서, 프로그래머와 맵 기획자의 불필요한 반복(수정) 작업이 완벽히 사라졌고 팀 전체의 협업 시너지가 크게 향상되었습니다.

## 💡 Key Features
1. **생존 패러미터 관리 시스템:** 산소와 배고픔이 실시간으로 줄어들고, 횃불의 게이지에 따라 2D 광원(Lighting)의 범위가 동적으로 줄어드는 몰입감 넘치는 시스템 구현.
2. **로프 액션:** Joint 2D를 활용한 로프 매달리기 및 스윙 액션.
3. **타일맵 & 함정 상호작용:** 가시 함정, 움직이는 몬스터 등 다양한 기믹 구현.
